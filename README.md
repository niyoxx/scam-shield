# Scam Shield

An ML system that detects scam and phishing messages and explains, in plain English, why a message is risky.

**Dataset:** [UCI SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection). Download it into `data/` (not tracked in git).

**Status:** Step 1 done (data loading and exploration). Baseline models coming next in the next steps
